# Bloom

Portfolio site for Akira Uriel. Plain HTML, CSS and JavaScript, no build step: open `index.html` through any static server.

Flower photographs in `assets/flowers` are from Wikimedia Commons. Most are CC0. Two are CC BY-SA 4.0:

- `spider-lily.jpg`: "Red Spider Lily, Lycoris radiata" by Jim Evans
- `valley.jpg`: "Convallaria majalis inflorescence, Keila" by Ivar Leidus

Both are shown as ASCII renderings, which are adaptations under the same licence.
